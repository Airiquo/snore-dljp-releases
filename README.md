# snore-dljp downloads

Desktop video and audio downloader using yt-dlp, Python/Tkinter, and PyInstaller. Download Windows and Apple Silicon macOS builds from Releases.

Source is maintained in a private repository. FFmpeg/ffprobe and Deno are external requirements. Updates check this repository automatically and ask before installation.

Windows builds pass native command/process, updater, and packaged-download checks. Full desktop layout checks run on macOS; interactive Windows visual verification remains pending.
